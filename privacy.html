プライバシー ポリシー

syllabus_fetcher（最終更新日: 2026年11月6日）

取得する情報

本ツールは、Google アカウントの認可により、本ツールが作成した Google カレンダーへのアクセス権（スコープ https://www.googleapis.com/auth/calendar.app.created）のみを取得します。利用者のほかのカレンダー、予定、連絡先、メールなどにはアクセスしません。

情報の利用目的

取得したアクセス権は、大学の授業・休講・補講の予定を、本ツールが作成したカレンダーに登録・更新・削除するためだけに使用します。

情報の保存

認可トークンは利用者自身の PC 内にのみ保存されます。開発者や第三者のサーバーに送信・保存することはありません。

第三者への提供

取得した情報を第三者に提供・販売することはありません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他アプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセス権の取り消し

利用者は Google アカウントの「サードパーティ製のアプリとサービス」 から、いつでも本ツールのアクセス権を取り消せます。
